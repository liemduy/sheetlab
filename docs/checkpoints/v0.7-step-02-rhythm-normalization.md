# v0.7 Step 02 - Rhythm Normalization

## Goal

Add a normalized rhythmic view where each voice in each measure always sums to
the measure duration.

## Result

- Added `normalizeMeasureVoice`.
- Added implicit rest filling for empty time ranges.
- Explicit rest events stay real event segments.
- Overlapping events throw `Rhythm event overlap`.
- Overflowing events throw `Rhythm event overflows measure`.
- Added `normalizeScoreRhythm` for full-score rhythmic inspection.
- Added `assertNormalizedVoiceIsFull`.
