# v0.6 Step 03 - Slot-Based Click Placement

## Goal

Make actual note placement use the same snapped input grid as the visible ghost
and cursor.

## Result

- Ghost notes now resolve through the active input grid instead of raw hover
  beats.
- Click placement now snaps to the selected duration slot before writing into
  the score model.
- Clicking between quarter-note slots places the note on the nearest visible
  quarter slot.
- The note created after click matches the cursor measure and beat seen before
  clicking.
