# V0.2 Checkpoint 08: Overlay And VexFlow Alignment

## Goal

Align hover/click/select/playhead geometry with the visible VexFlow note area instead of the raw measure barline width.

## Acceptance Criteria

- Shared geometry reserves first-measure space for clef/time signature.
- `getBeatX` returns positions inside the measure content area.
- Pointer mapping clamps before-content positions to beat zero.
- VexFlow `Stave` note start positions use the same content-left geometry as the overlay.
- Existing hover ghost, hit target, selection, and playhead behavior remains testable.

## Test Plan

- Run focused geometry/interaction/renderer tests.
- Run `npm.cmd run test`.
- Run `npm.cmd run typecheck`.
- Run `npm.cmd run build`.

## Result

- Passed focused tests: 3 test files, 12 tests.
- Passed `npm.cmd run test`: 11 test files, 52 tests.
- Passed `npm.cmd run typecheck`.
- Passed `npm.cmd run build`.
- Added measure content geometry helpers in `src/features/sheet/layout.ts`.
- Updated `src/features/sheet/notationGeometry.ts` and `src/features/sheet/interaction.ts` to use content-aware beat positions.
- Updated VexFlow note placement to share the same content-left geometry.

## Notes
