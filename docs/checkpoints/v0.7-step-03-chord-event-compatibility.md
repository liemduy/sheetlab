# v0.7 Step 03 - Chord Event Compatibility

## Goal

Teach the score pipeline that one rhythmic column can contain multiple pitches,
instead of treating piano chords as separate unrelated note events.

## Result

- Added a `chord` score event with a `pitches` array.
- Added score-event helpers for pitched events, primary pitch, and pitch labels.
- Updated project validation so JSON save/load accepts chord events.
- Updated playback timeline/audio to keep chord pitches together.
- Updated editor SVG overlays to render chord noteheads from one selectable
  event column.
- Updated VexFlow adapter and PDF export to preserve chord pitch columns.
