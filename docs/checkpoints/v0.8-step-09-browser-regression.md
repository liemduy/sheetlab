# v0.8 Step 09 Browser Regression Checkpoint

## Scope

Verify the repaired input cursor behavior in a real browser session, not only unit tests.

## Browser Scenario

1. Open `http://localhost:5173/`.
2. Start with the default grand staff piano score.
3. Select eighth note entry and hover the first treble slot.
4. Place two eighth notes sequentially.
5. Select sixteenth note entry and place the next slot.
6. Hover a thirty-second slot to confirm the slot box remains readable.
7. Hover the grand-staff dead zone between treble and bass.
8. Hover low treble and bass ledger positions.

## Pass Criteria

- The first slot box is centered on the ghost note column.
- Two eighth-note placements create exactly two visible score events.
- A shorter duration expands the first measure, but the visible slot box keeps a stable readable width.
- Thirty-second input still renders one readable active slot instead of a thin or offset stripe.
- Hovering the dead zone between treble and bass clears both ghost and active slot.
- Ledger preview lines stay local to the notehead instead of spanning across systems or staves.
