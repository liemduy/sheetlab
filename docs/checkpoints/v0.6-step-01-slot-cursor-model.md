# v0.6 Step 01 - Slot Cursor Model

## Goal

Introduce a real music input cursor before changing the visual slot UI.

## Result

- Added `InputCursor` with staff, measure, beat, duration, pitch preview, and
  mode.
- Cursor now updates from hover position.
- Cursor advances after successful note/rest placement:
  - quarter from beat 1 to beat 2
  - half from beat 1 to beat 3
  - whole from beat 1 to the next measure
- Cursor duration updates when the toolbar duration changes.
- App state summary now shows the current input cursor.
