# v0.6 Step 04 - Delete Hover Control

## Goal

Make the selected-note delete control behave like a real UI control instead of
competing with the note-input ghost/cursor.

## Result

- The small delete `x` now has a larger invisible hit target.
- Delete works from a normal click path, not only from `mouseDown`.
- Hovering the delete control hides the ghost note and active input cursor.
- Ghost/cursor/slot overlays explicitly disable pointer events on descendants.
- Existing notes and delete controls render above the note-input preview, so the
  delete control is visually readable.

## Browser QA

Passed on `http://localhost:5173/`:

- Browser interaction created 1 note event.
- Browser delete-control click removed it back to 0 note events.
- Earlier coordinate testing exposed that the delete hit area was too fragile;
  this step fixed that with a larger delete target and click handler.
