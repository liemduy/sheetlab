# v0.5 Step 06 - Grand Staff Piano

## Goal

Make basic piano entry viable across treble and bass staves.

## Result

- Score type changes now bring the user back to the notation surface.
- Duration and Note/Rest tool changes now return focus to the notation surface,
  which prevents toolbar clicks from leaving users away from the staff.
- Added a hover guide that highlights the active staff and labels it `Treble` or
  `Bass`.
- Fixed duration editing semantics: changing duration after placing a note now
  affects the next note, unless the user manually clicked an existing note first.
- Added automated coverage for independent treble/bass durations in a grand
  staff score.
