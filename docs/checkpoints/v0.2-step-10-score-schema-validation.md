# V0.2 Checkpoint 10: Score Schema Validation

## Goal

Add a lightweight runtime validation layer so imported or stored project JSON must match the MVP score schema before entering app state.

## Acceptance Criteria

- `deserializeScore` rejects JSON that is not a valid SheetLab score.
- Saved valid projects still round-trip without data loss.
- Local storage load fails safely to `null` for invalid stored JSON.
- Existing import/load behavior remains covered by app tests.

## Test Plan

- Run focused score factory/storage/fixture tests.
- Run `npm.cmd run test`.
- Run `npm.cmd run typecheck`.
- Run `npm.cmd run build`.
