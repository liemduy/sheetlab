# v0.4 Step 04 - Insert Mode

## Goal

Let users fix a missing note without deleting everything after it.

## Result

- The toolbar now has `Place` and `Insert` placement modes.
- `Place` keeps the previous direct-placement behavior.
- `Insert` adds the new event at the clicked position and shifts later events in the same staff to the right by the inserted duration.
- If the shifted tail passes the final bar, the score auto-adds another measure.
- Insert is rejected when it would split an existing longer event.
