# v0.7 Step 06 - Grand Staff Timeline Columns

## Goal

Make grand-staff piano input feel like shared rhythmic columns instead of two
unrelated staves.

## Result

- Added shared timeline column guides across treble and bass staves.
- The active timeline column highlights once per rhythmic slot, not separately
  per staff.
- The active input cursor now spans both staves in grand-staff mode.
- Insert cursor also spans the full piano system.
- Per-staff rhythm slot dots remain visible for local staff feedback.
