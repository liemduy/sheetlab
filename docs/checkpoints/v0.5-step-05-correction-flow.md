# v0.5 Step 05 - Correction Flow

## Goal

Make the basic user correction loop pass: select, drag-repair, delete, undo, and
redo.

## Result

- Reset now returns placement mode to `Place`, so starting a fresh score does not
  leave the user accidentally in Insert mode.
- The notation stage now fits the paper width instead of cropping the right side
  of the system.
- VexFlow SVG inline dimensions are overridden by responsive CSS, so the staff
  and interaction overlay scale together.
- Added a stage spacer so responsive notation keeps its height instead of
  collapsing around absolute SVG layers.
- Kept the existing drag and delete correction interactions, and covered the
  reset safety behavior with tests.
