# Checkpoint 02: React + TypeScript Scaffold

## Step Goal

Create the Vite React + TypeScript app foundation.

## Expected Result

- The app has a package manifest and Vite configuration.
- The app has a React entrypoint at `src/main.tsx`.
- The app renders a basic editor shell with top toolbar, left settings panel, and central sheet surface.
- The project has scripts for `build`, `typecheck`, and `test`.

## Tests

- Install dependencies with `npm.cmd install`.
- Run `npm.cmd run typecheck`.
- Run `npm.cmd run build`.

## Pass Criteria

- TypeScript build mode passes.
- Production build completes without errors.
