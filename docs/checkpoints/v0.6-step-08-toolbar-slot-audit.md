# v0.6 Step 08 - Toolbar And Slot Audit

## Goal

Audit the input cursor slot logic and clean up the toolbar after product review.

## Result

- Clarified the slot model:
  - slot count is derived from the active duration and the time signature
  - in 4/4, quarter input has 4 slots per measure
  - in 4/4, thirty-second input has 32 slots per measure
- Added `thirtySecond` duration support across:
  - score types
  - duration beat math
  - project validation
  - editor toolbar
  - VexFlow duration mapping
  - input cursor slot tests
- Replaced visible duration labels with musical symbols while preserving
  accessible button names.
- Added visible toolbar group labels:
  - Duration
  - Entry
  - Write mode
  - Transport
  - File
- Widened the default staff layout on the paper by reducing side padding and
  increasing measure width.

## Browser QA

Passed on `http://localhost:5173/`:

- Quarter duration button text is `♩`.
- Thirty-second duration button exists.
- Toolbar group labels are visible.
- Default quarter slot count is 16 total on the default 4-measure treble score.
- Switching to thirty-second gives 128 total slots on the default 4-measure
  treble score.
