# v0.7 Step 05 - Chord Insertion

## Goal

Support piano-style note columns: adding another pitch to the same rhythmic slot
should create a chord instead of overwriting the previous note.

## Result

- Placing a note on an occupied same-duration slot merges the pitches into one
  chord event.
- Duplicate pitches are deduped inside a chord column.
- Chord pitches are sorted by pitch height for stable rendering/playback labels.
- Placing with a different duration at the same start still replaces the old
  event.
- Updating or moving a chord preserves its pitch list instead of collapsing it
  back to a single note.
- Added App-level coverage for real click-to-chord behavior.
