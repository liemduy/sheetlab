# v0.5 Step 02 - Editor Viewport

## Goal

Remove the hidden horizontal-scroll editing trap and keep the first editable
staff reachable after reset.

## Result

- The notation viewport no longer exposes horizontal scrolling in edit mode.
- The first staff remains readable at the current narrow in-app browser width.
- Reset scrolls the notation viewport back into view.
- VexFlow SVG output now receives a `viewBox` so it can be scaled later without
  losing coordinate alignment.

## Browser QA

Passed in the in-app browser:

  toolbar/title.
