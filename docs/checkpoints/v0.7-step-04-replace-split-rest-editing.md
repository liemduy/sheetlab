# v0.7 Step 04 - Replace And Split Rest Editing

## Goal

Make note placement behave like a measure timeline: placing, moving, or deleting
events should keep the measure rhythmically complete instead of leaving loose
gaps.

## Result

- Added tick splitting into supported note/rest durations.
- `tryPlaceScoreEvent` can replace an event at the same slot.
- Placing into a generated rest splits that rest around the new event.
- Deleting a note fills the slot back with compact generated rests.
- Moving/updating notes treats generated rests as empty space, not collision.
- Playback skips rest fillers.
- Insert snapping ignores generated rests.
- Generated rests render as visual-only filler, so they do not block pointer
  placement/select/delete interactions.
