# v0.4 Step 02 - Delete Target

## Goal

Let users delete a placed note without going back to the toolbar.

## Result

- Selecting an event shows a small `x` target near the note/rest.
- The `x` target is separate from the note hit target, so deleting does not place or reselect a note.
- `Delete` and `Backspace` remove the selected event unless the user is typing in a form field.
- The existing toolbar Delete button still works.
