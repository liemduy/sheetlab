# v0.5 Step 07 - Backend PDF Export

## Goal

Replace browser print export with a real backend PDF download.

## Result

- Added a Node dev server that serves Vite and handles `POST /api/export-pdf`.
- Added a PDFKit-based score PDF generator.
- Updated `npm run dev` to start the backend-enabled dev server.
- Updated frontend export to send the current score JSON to the backend and
  download the returned PDF blob.
- Removed the `window.print()` export behavior from the app flow.
- Added tests that verify the generated buffer starts with `%PDF-` and the
  frontend calls the backend endpoint.
