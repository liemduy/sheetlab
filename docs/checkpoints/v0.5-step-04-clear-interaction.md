# v0.5 Step 04 - Clear Interaction

## Goal

Make Place and Insert mode behave predictably under real pointer input.

## Result

- Added an insert-position snapper so clicks inside an existing event snap to
  the nearest valid event boundary instead of failing with `event-overlap`.
- Updated the insert preview so the blue insertion cursor and ghost note render
  at the exact snapped beat that will be used on click.
- Kept insert-mode note hit targets smaller, which leaves more clickable space
  between adjacent notes.
- Restored the notation viewport after clicking Place or Insert from the
  toolbar, so users do not lose the staff while switching tools.
