# V0.2 Checkpoint 07: VexFlow Notes And Rests

## Goal

Render score events as real VexFlow notes/rests instead of relying on the old hand-drawn SVG event glyphs.

## Acceptance Criteria

- Score notes render as VexFlow `StaveNote` glyphs.
- Score rests render as VexFlow rest glyphs.
- Accidentals from the internal score model map to VexFlow modifiers.
- Measure gaps are filled with hidden rests so VexFlow keeps beat positions stable.
- VexFlow-rendered event glyphs expose DOM metadata for future selection/highlight work.
- Unit test output is readable and no longer flooded by jsdom canvas warnings.

## Test Plan

- Run focused renderer/adapter tests.
- Run `npm.cmd run test`.
- Run `npm.cmd run typecheck`.
- Run `npm.cmd run build`.
