# V0.2 Checkpoint: Hover And Click Accuracy

## Goal

Fix and lock down the most basic editor interaction: the note placed by clicking the visible staff must match the pitch/beat the user points at.

## Finding

Manual browser interaction showed the visible VexFlow staff and the transparent overlay were vertically misaligned. A click around the visible treble middle staff area could produce a note around `B3` instead of the expected `B4`.

## Fix

- Added `VEXFLOW_STAVE_TOP_LINE_OFFSET`.
- Updated VexFlow stave placement so the first rendered staff line aligns with `getStaffTop`.
- Added automated real-pointer tests using a non-zero SVG bounding box.

## Automated Coverage

- `StaffRenderer` now tests VexFlow staff-line alignment with overlay geometry.
- `StaffRenderer` now tests real pointer coordinates on treble middle line map to `B4`.
- `App` now tests the full hover/click flow:
  - hover shows ghost note,
  - editor state shows `treble M1 B1 B4`,
  - click places `Note B4 measure 1 beat 1`.

## Gate

- Passed `npm.cmd run test`: 11 test files, 57 tests.
- Passed `npm.cmd run typecheck`.
- Passed `npm.cmd run build`.
