# v0.6 Step 02 - Visible Rhythm Slots

## Goal

Make note entry feel closer to MuseScore by showing duration-based rhythm slots
and an active input cursor on the staff.

## Result

- Added visible rhythm slots for the selected duration:
  - quarter: 4 slots per 4/4 measure
  - half: 2 slots per 4/4 measure
  - eighth: 8 slots per 4/4 measure
- Added a blue active input cursor with a vertical line and note-position box.
- Cursor beat now snaps to the active duration slot, so it no longer sits
  between two visible slots.
- The active slot highlights at the same staff, measure, and beat as the input
  cursor.
- Slot and cursor overlays do not intercept pointer events.

## Browser QA

Passed on `http://localhost:5173/`:

- A4 treble score shows 16 quarter-note slots across 4 measures.
- Hovering on the staff creates exactly 1 active input cursor.
- The hovered cursor snaps to a visible quarter slot.
- Exactly 1 rhythm slot becomes active at the cursor position.
