# v0.4 Step 05 - Browser QA And Full Gate

## Goal

Verify the editing upgrade as a real user flow, not only with unit tests.

## Browser QA

Passed in the in-app browser at `http://localhost:5173/`:

- Page size selector shows `A4` by default.
- Selecting `Letter` updates the editor state to `Letter`.
- Clicking the visible staff places a note and selects it.
- Dragging the placed note vertically commits `Event moved`.
- Clicking the small `x` target deletes the selected event and returns the event count to 0.
- Switching to `Insert` mode and clicking the staff commits `Event inserted`.

The browser viewport is narrow, so the browser QA focused on visible staff interactions. The full insert-between-notes reflow behavior is covered by automated tests, including shifting later events and auto-adding a measure when the tail spills past the final bar.
