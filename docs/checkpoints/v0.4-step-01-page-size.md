# v0.4 Step 01 - Page Size

## Goal

Make the sheet canvas use a real page-size concept instead of a generic flexible paper.

## Result

- Score projects now store `pageSize`.
- New scores default to `a4`.
- Older saved JSON without `pageSize` is migrated to `a4` on load.
- The left settings panel has a Page size selector with `A4` and `Letter`.
- The paper element gets `paper-a4` or `paper-letter` classes for visual sizing.
