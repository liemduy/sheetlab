# v0.7 Step 01 - Tick Duration Model

## Goal

Introduce a tick-based rhythmic foundation before changing notation editing
behavior.

## Result

- Added `TICKS_PER_QUARTER = 480`.
- Added duration-to-tick conversion:
  - whole = 1920
  - half = 960
  - quarter = 480
  - eighth = 240
  - sixteenth = 120
  - thirty-second = 60
- Added measure tick conversion from time signature beats.
- Added beat/tick conversion helpers.
