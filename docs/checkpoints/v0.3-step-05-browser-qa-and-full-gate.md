# v0.3 Step 05 - Browser QA And Full Gate

## Goal

Verify the v0.3 notation polish in the real browser before closing the sequence:

- The sheet surface should no longer look like a broken canvas.
- The instruction note must not overlap the staff.
- Hover ghost and click placement must align under real pointer interaction.
- Ledger lines must appear for notes outside the staff.
- The project must pass the full automated gate.

## Browser QA

Initial browser QA caught a gate failure on a narrow in-app viewport: the instruction note overlapped the treble staff because the notation stage was being squeezed to the paper width while VexFlow/SVG content still behaved like a 920px music system.

Fix applied:

- Added a dedicated notation scroll viewport.
- Kept the notation stage at the real 920px SVG music width.
- Moved horizontal overflow responsibility to the notation viewport.
- Reduced mobile notation spacing enough to keep the surface readable.

User-like browser flow after the fix:

- Reset the score.
- Scrolled to the visible staff area.
- Hovered over the first staff: ghost note appeared at the pointer target.
- Clicked the same location: a placed note appeared at the same beat/pitch and the app reported 1 event.
- Hovered above the staff: ghost note rendered with ledger line.
- Clicked the ledger position: placed note rendered with ledger line and the app reported 2 events.
