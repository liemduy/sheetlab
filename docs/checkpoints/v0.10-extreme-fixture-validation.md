# v0.10 Extreme Fixture Validation Checkpoint

Date: 2026-05-14

## Scope

- Added a fixture catalog with stable ids, labels, risk, capabilities, and expected event counts.
- Expanded browser stress QA so each extreme score fixture is loaded through the real UI, rendered, exported to JSON, exported to PDF, and captured as a screenshot.
- Added `getScoreMusicIssues` as a combined music validation layer for rhythm, repeats, tuplets, lyric maps, range marks, clef changes, ties, slurs, and duplicate event ids.
- Added playback correctness snapshots for repeat order, tuplet timing, chord simultaneity, tie sustain, key signatures, and ottava pitch shifts.
- Added a toolbar Demo loader and a Music validation summary in the settings panel.
- Strengthened renderer and PDF parity checks with fixture catalog metadata.
