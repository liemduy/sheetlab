# v0.4 Step 03 - Drag Move

## Goal

Let users correct a placed note by dragging it instead of deleting and recreating it.

## Result

- Mouse down on a placed event starts a drag candidate.
- Moving more than a tiny threshold shows a ghost preview at the snapped target pitch/beat.
- Mouse up commits the move only when the target position is valid.
- Moving onto another event is rejected instead of silently replacing it.
- Moved events keep their duration and accidental behavior.
