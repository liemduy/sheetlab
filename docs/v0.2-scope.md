# SheetLab V0.2 Scope

## Product Goal

Make the editor surface look and feel like credible sheet music while preserving the V0.1 editing loop.

V0.2 is not a feature expansion sprint. It is a notation credibility sprint: clefs, staff layout, notes, rests, accidentals, page layout, playback highlight, and export should feel closer to real sheet music than the V0.1 debug SVG renderer.

## Target Outcome

By the end of V0.2, SheetLab should support:

- A renderer powered by VexFlow for real notation glyphs.
- Treble-only and grand-staff rendering that looks like a beginner sheet editor.
- Notes, rests, and accidentals rendered as music notation rather than placeholder shapes.
- The existing hover, ghost, click-to-place, select, update, delete, undo/redo, playback, save/load/import/export, and print flows.
- A page surface that resembles a printable sheet music page.
- A visual QA checklist that catches sheet credibility regressions.

## In Scope

- VexFlow installation and renderer adapter.
- Keeping the existing score model as the source of truth.
- Mapping the internal score model to VexFlow notes and rests.
- Treble and bass clef rendering through VexFlow.
- Accidentals for sharp, flat, and natural.
- Overlay interaction above the rendered notation.
- Page layout polish for screen and print.
- Toolbar grouping/polish where it supports notation editing.
- Import JSON validation.
- Refactoring `App.tsx` orchestration if needed to keep V0.2 maintainable.
- Automated tests for model-to-renderer behavior and existing editing flows.
- Manual user-style demo scenarios.

## Out Of Scope

- Full MusicXML import/export.
- MIDI device input.
- Singing practice.
- Multi-voice notation on the same staff.
- Chords and cross-staff notation.
- Tuplets, ties, slurs, lyrics, articulations, beams beyond what VexFlow handles automatically for the MVP input.
- Custom PDF template engine.

## Product Pass Criteria

- A user no longer sees placeholder `G` or `F` clef letters.
- Notes and rests look like notation glyphs.
- Accidentals appear beside notes.
- Treble and grand staff layouts are visually recognizable.
- Existing V0.1 flows still work.
- Print/export hides editor chrome and preserves the sheet.

## Technical Pass Criteria

- `npm.cmd run test` passes.
- `npm.cmd run typecheck` passes.
- `npm.cmd run build` passes.
- VexFlow is isolated behind adapter/renderer code.
- The internal score model remains renderer-independent.
